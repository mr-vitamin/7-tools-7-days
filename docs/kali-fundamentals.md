# Optional Linux and networking study topics

This is an optional study outline, separate from the completed seven-tool project. It lists topics for future practice.

| Area | Topics for further practice |
| --- | --- |
| Files | pwd, ls, cd, mkdir, cp, mv, less, find |
| Text | grep, pipes, redirects, quoting |
| Permissions | users, groups, ownership, chmod, sudo, least privilege |
| Services | ps, systemctl status, journalctl, service lifecycle |
| Networking | IP addressing, subnetting, routing, DNS, TCP/UDP, ports |
| Diagnostics | ip addr, ip route, ss, connectivity and name resolution |
| Help and packages | man, --help, package information, tool versions |

For a future exercise, I would record the question, exact command, observed result, explanation, and any unresolved issue. The [daily investigation template](../templates/daily-investigation.md) provides a reusable starting point.

The completed investigations and [final report](../reports/final-report.md) contain the results from this project.
